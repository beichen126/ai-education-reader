# Product Roadmap

这里记录面向用户的产品方向；已经交付的能力见 [CHANGELOG.md](CHANGELOG.md)，不把已完成事项伪装成未来计划。

## 当前版本：v2.5.1

AI Education Reader 是一套以 PDF 为中心的本地学习工作区：资料、章节、阅读进度、页面笔记、会话、分支、学习卡片和学习成果可以沿着同一份原文持续积累。v2.5.1 在现有本地数据安全能力上补齐大型备份的低内存恢复路径。

v2.5.1 已交付：

- **本地数据安全中心**：统一展示浏览器持久化保护、origin 配额风险、各类本地占用和最近一次完整备份；支持在用户操作下重新申请持久化保护；
- **安全的 ZIP / JSON 恢复**：选择文件后先展示覆盖范围，允许取消或先导出当前数据，并要求勾选确认后才执行整包替换；不伪装成无法保证引用完整性的自动合并；
- **API 配置检查**：逐项检查地址、Key、模型名和 Vision 策略，通过 `GET /models` 核对连通性、鉴权以及服务可枚举时的模型名，不发送聊天或资料，不改变会话推理强度；
- **发布一致性门禁**：package、README badge、Roadmap 当前版本和 Changelog 最新版本必须一致，FAQ 编号不能重复；
- **备份与大型文件**：保留 portable ZIP v2、Backup V7 数据模型和大文件流式写盘；记录最近一次成功完整备份，API Key 继续排除在备份之外；
- **大型备份恢复**：portable ZIP 按块读取，PDF / 图片直接暂存到 OPFS，校验完成后再原子替换元数据；失败时回滚暂存内容并保留原数据；
- **兼容性不变**：旧 V1–V7 JSON Backup 继续可导入，既有会话、卡片、标记、PDF 与提示词不需要迁移。

v2.2.0–v2.4.7 已交付学习卡片、消息标记统一、双向回链、可评分学习中心、三态可拖动侧栏、完整英文界面、PDF 导航/目录鲁棒性修复，以及 40%–150% 的连续缩放体验；细节见 [CHANGELOG.md](CHANGELOG.md)。

## v2.1.0 已交付

v2.0.0 的 Prompt-native 工作方式也已经交付：

- **会话模式**：选择 AI 讲解方式，模式变化从下一条消息开始，历史回答仍保留当时的学习方式；
- **学习成果**：把当前 PDF 上下文加工成笔记、题目、总结、学习指南或自定义成果；
- **快捷追问**：把常见的下一步问题变成真正的用户消息，主线和分支都能继续使用；
- **系统协议**：查看目录识别、题目结构等机器输出规则及其校验说明；
- **可恢复学习数据**：Prompt 配置、模式历史、分支、成果和 PDF 关系一起进入 Backup V6，旧 V1–V5 backup 仍可导入。

## v2.1.0 已交付

- **已完成：** 用户可创建和切换自定义会话模式；章节范围使用紧凑 popup，并保留完整页码和 `[)` / `[]` 边界语义。
- **已完成：** README 已重构为普通用户产品说明书，补充 PDF 一等对象、产品差异、按步骤使用、隐私备份和 FAQ。
- **已完成：** 应用内无 API 产品引导、可靠的阅读进度保存、PDF 冷启动性能基线，以及可切换的虚拟化连续滚动。

## 接下来

### 更大的本地资料库

继续降低大型 PDF、图片和 Backup 在浏览器内的峰值内存占用，完善 OPFS 垃圾回收、失败恢复和流式导出。当前 OPFS-first 与 IndexedDB fallback 已经是基础能力。

### 更顺手的复习工作流

围绕页面笔记、学习成果和快捷追问增加复习组织能力，但仍保持“先回到原文，再加工内容”的 PDF 一等对象原则。

### 浏览器离线与安装体验

评估 PWA、离线启动和本地资源缓存，前提是不会把 API Key 或学习资料引入不必要的云端同步。

### PPTX 资料导入

仍然是计划项：PPT/PPTX 需要先在浏览器本地转换为规范 PDF，再复用现有 Document / Chapter / Reader / Context 链路；不会建设第二套 PPT 阅读器。只有完成真实格式保真度门禁后才会开启。

## 明确不做

- 不把 PDF 降级成某条会话的临时附件；
- 不用云端账户或项目后端默默同步本地教材；
- 不让内部 Prompt 类型、实现细节替代用户可以理解的学习入口；
- 不为 PPTX 建立与 PDF 分裂的第二套目录、阅读和 Context 系统。
