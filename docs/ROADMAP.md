# Product Roadmap

这里记录面向用户的产品方向；已经交付的能力见 [CHANGELOG.md](CHANGELOG.md)，不把已完成事项伪装成未来计划。

## 当前版本：v2.2.0

AI Education Reader 是一套以 PDF 为中心的本地学习工作区：资料、章节、阅读进度、页面笔记、会话、分支、学习卡片和学习成果可以沿着同一份原文持续积累。v2.2.0 把「单条 AI 回复」变成可收藏、可筛选、可回链的**学习卡片**一等对象，同时整顿主导航并返工连续阅读的实现。

v2.2.0 已交付：

- **学习卡片**：把一条已完成的 AI 回复原样保存为卡片（不调用 AI、不复制整段会话），同一条回复只会有一张卡；
- **学习中心**：全局入口独立于当前会话，支持按来源 PDF 筛选、搜索、重命名、删除、五种排序与稳定随机顺序；
- **双向回链**：卡片可回到精确的会话/分支/AI 回复，也可跳到来源 PDF 的精确页；Reader「关于此页」同时列出会话与学习卡片；
- **来源删除语义**：删除会话或 PDF 不删除卡片，只保留文件名与页码快照并停用跳转；
- **导航整顿**：提示词管理进入设置，帮助固定在侧栏最后，消息菜单收敛为「从这里分支 / 开启特殊分支 / 保存本轮回复为学习卡片」；
- **连续阅读返工**：分页与连续渲染器互斥、真正的窗口化 DOM、混合页尺寸锚点稳定、滚动热路径不再全量查询；
- **PDF 阅读方式点击即保存**，设置写失败可回滚、可重试；
- **Backup V7**：卡片与卡片列表偏好进入备份，V1–V6 继续可导入。

## v2.1.0 已交付

v2.0.0 的 Prompt-native 工作方式也已经交付：

- **会话模式**：选择 AI 讲解方式，模式变化从下一条消息开始，历史回答仍保留当时的学习方式；
- **学习成果**：把当前 PDF 上下文加工成笔记、题目、总结、学习指南或自定义成果；
- **快捷追问**：把常见的下一步问题变成真正的用户消息，主线和分支都能继续使用；
- **系统协议**：查看目录识别、题目结构等机器输出规则及其校验说明；
- **可恢复学习数据**：Prompt 配置、模式历史、分支、成果和 PDF 关系一起进入 Backup V6，旧 V1–V5 backup 仍可导入。

## v2.1.0 已交付

- **已完成：** 用户可创建和切换自定义会话模式；章节范围使用紧凑 popup，并保留完整页码和 `[)` / `[]` 边界语义。
- **已完成：** README 已重构为普通用户产品说明书，补充 PDF 一等对象、产品差异、按步骤使用、隐私备份和 FAQ。
- **已完成：** 应用内无 API 产品引导、可靠的阅读进度保存、PDF 冷启动性能基线，以及可切换的虚拟化连续滚动。

## 接下来

### 更大的本地资料库

继续降低大型 PDF、图片和 Backup 在浏览器内的峰值内存占用，完善 OPFS 垃圾回收、失败恢复和流式导出。当前 OPFS-first 与 IndexedDB fallback 已经是基础能力。

### 更顺手的复习工作流

围绕页面笔记、学习成果和快捷追问增加复习组织能力，但仍保持“先回到原文，再加工内容”的 PDF 一等对象原则。

### 浏览器离线与安装体验

评估 PWA、离线启动和本地资源缓存，前提是不会把 API Key 或学习资料引入不必要的云端同步。

### PPTX 资料导入

仍然是计划项：PPT/PPTX 需要先在浏览器本地转换为规范 PDF，再复用现有 Document / Chapter / Reader / Context 链路；不会建设第二套 PPT 阅读器。只有完成真实格式保真度门禁后才会开启。

## 明确不做

- 不把 PDF 降级成某条会话的临时附件；
- 不用云端账户或项目后端默默同步本地教材；
- 不让内部 Prompt 类型、实现细节替代用户可以理解的学习入口；
- 不为 PPTX 建立与 PDF 分裂的第二套目录、阅读和 Context 系统。
