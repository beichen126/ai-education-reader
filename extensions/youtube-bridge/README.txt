AI 学习阅读器 YouTube 字幕桥接扩展

1. 解压本 ZIP。
2. Chrome 打开 chrome://extensions ，或 Edge 打开 edge://extensions 。
3. 打开「开发者模式」，点击「加载已解压的扩展程序」，选中包含 manifest.json 的目录。
4. 刷新 https://beichen126.github.io/ai-education-reader/ 。
5. 添加资料 → YouTube 视频解析，粘贴链接后提取。

提取会新开 YouTube 标签页，成功后返回阅读器。若需验证，请在 YouTube 页面完成。
字幕通过浏览器本机读取，不使用字幕服务器，不传出 Cookie。无法保证无字幕或受限制的视频可提取。
